1.4 单次试验流程

随机初始状态 → 策略控制 500 步（10 秒仿真时间）→ 判定恢复。

恢复判定标准：位置误差 < 0.3 m 且 速度 < 0.3 m/s，持续 0.3 秒（15 步）。

失败模式：坠机（z ≤ 0）或超时（500 步未达标）。

三、结果分析

3.1 跨平台反转模式

CTBR: Proto 97.8% → Iris 91.1% → CF 1.3% (单调下降 — 过拟合) CTBR+DR: Proto 93.8% → Iris 83.9% → CF 96.7% (U 型 — 均衡泛化) CTBR+ID: Proto 37.3% → Iris 89.0% → CF 98.1% (单调上升 — 理想动力学)

3.2 CTBR — 训练平台专家

Proto 97.8%（最高），Iris 91.1%，CF 仅 1.3%。精确参数匹配在训练平台上最优，但参数偏移后性能崩溃。Proto 与 Iris 质量/惯量分布相似，CTBR 可部分泛化；CF 参数差异过大则完全失效。

3.3 CTBR+DR — 均衡泛化型

三平台 83.9%–96.7%。域随机化牺牲顶峰性能换取全局鲁棒性。U 型曲线表明在物理约束最紧的 Iris (T/W=1.9) 上 DR 反而最弱——随机化的收益被推力不足的物理极限所抵消。

3.4 CTBR+ID — 快响应平台王者

CF 98.1%、Iris 89.0%、Proto 仅 37.3% 且坠机率 27.4%。成功率与电机响应率近乎完美正相关：

CF (τ≈0.0001s, 响应≈100%) → 98.1%, 坠机率 1.9% Iris (τ=0.0125s, 响应≈80%) → 89.0%, 坠机率 11.0% Proto(τ=0.033s, 响应≈45%) → 37.3%, 坠机率 27.4%

CTBR+ID 在训练时从未见过电机延迟。部署到慢电机平台时，每步仅有 45% 指令生效——指令与响应之间的巨大偏差导致震荡和坠机。

四、结论

  1. 理想动力学 (CTBR+ID) 能够在快响应平台上实现零成本仿真迁移（CF 98.1%、Iris 89.0%），但在电机延迟显著的平台上失效（Proto 37.3%）。
  2. 精确建模 (CTBR) 在训练平台上最优（Proto 97.8%），但无法跨平台泛化（CF 1.3%）。
  3. 域随机化 (CTBR+DR) 是最均衡的方案（83.9%–96.7%），以牺牲顶峰性能换取全局鲁棒性。
  4. 电机单步响应率是 CTBR+ID 迁移成功的关键预测因子：100%→98.1%；80%→89.0%；45%→37.3%。
  5. 推重比决定了可恢复性的物理下限：Iris (T/W=1.9) 对所有策略都是最困难的平台。
